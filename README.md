# deteccao-de-fraudes-em-cartao
Projeto de Machine Learning voltado à detecção de fraudes em cartões de crédito, utilizando modelos de classificação como Regressão Logística, Random Forest e XGBoost. Foram aplicadas técnicas de balanceamento (Undersampling e SMOTE), ajuste de threshold e análise de métricas como Precision, Recall e F1-score.
